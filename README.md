## 📈 My Approach to Data Analysis

I follow a structured workflow when working with data:

### 1. Understand

Understand the dataset, business context, columns, and analytical objective.

### 2. Clean

Handle missing values, duplicates, incorrect data types, inconsistent categories, invalid values, and outliers.

### 3. Explore

Perform exploratory data analysis to understand distributions, relationships, patterns, and anomalies.

### 4. Analyze

Use statistical measures, aggregations, correlations, and trend analysis to answer analytical questions.

### 5. Visualize

Convert important findings into meaningful charts, reports, and dashboards.

### 6. Communicate

Present the results in a simple and understandable way so that the insights can support decision-making.
